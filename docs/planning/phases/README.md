# Phase plans (historical)

The files in this directory are the original phase-by-phase implementation plans
for the retired LangGraph runtime. They are kept as design history only.

The active runtime is coordinator-only (`coordinator-v1`); see
`docs/architecture/coordinator.md`, `docs/planning/migration-results.md` and the
`MCPA2A-*` ADRs in `docs/planning/decisions/`. LangGraph, checkpointer and
`travel-graph` references in these phase files are historical and are not
executable instructions for the current repository.
